# Nhóm 5 – CS434 AI

## 📌 Đề tài
**XÂY DỰNG WEBSITE ĐẶT THUÊ XE MÁY THÔNG MINH TÍCH HỢP AI CÁ NHÂN HÓA LỰA CHỌN PHƯƠNG TIỆN**
## ⚠️ Vấn đề thực tế
Hoạt động cho thuê xe thủ công gây ra nhiều hạn chế:
- Khó kiểm soát số lượng xe và tình trạng xe.
- Không tối ưu phân bổ xe giữa các chi nhánh.
- Thiếu lịch sử thuê và gợi ý phương tiện.
- Không có hệ thống báo cáo hỗ trợ quyết định kinh doanh.
- Trải nghiệm người dùng thiếu tính chuyên nghiệp.
Hệ thống được xây dựng nhằm khắc phục toàn diện các hạn chế trên.
## 🎯 Mục tiêu hệ thống
- Xây dựng hệ thống đặt thuê xe trực tuyến bằng nền tảng **.NET**  
- Số hóa quy trình quản lý xe, đơn thuê và người dùng  
- Tích hợp AI để gợi ý phương tiện cá nhân hóa  
- Cung cấp báo cáo, thống kê hỗ trợ tối ưu kinh doanh  
- Mang lại trải nghiệm chuyên nghiệp và nhanh chóng cho khách hàng  
## 🧩 Các chức năng chính
- Đăng ký / Đăng nhập  
- Xem danh sách & chi tiết xe  
- Tìm kiếm / Lọc nâng cao  
- Đặt thuê xe  
- AI gợi ý phương tiện  
- Chatbot tư vấn  
- Quản lý đơn thuê  
- Quản lý xe (Admin)  
- Thống kê, báo cáo  
- Thông báo, xác nhận 
## 🏗️ Công nghệ sử dụng
- ASP.NET MVC / ASP.NET Core MVC
- C# (.NET)
- Entity Framework / EF Core
- SQL Server
- ASP.NET Identity
- ML.NET / AI tích hợp trong backend .NET
